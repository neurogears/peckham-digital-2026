# Slides

Talk decks for the workshop. Each deck is a self-contained
[reveal.js](https://revealjs.com) presentation that opens in a new tab.

| Deck | Description |
| --- | --- |
| [Introduction to Bonsai](./decks/00-introduction.html) | What is visual reactive programming, what is Bonsai, and how to build a Bonsai workflow. |


The workflow and marble diagrams are adapted from the
[Homerton 2026 Bonsai course](https://github.com/neurogears/homerton-2026)
by NeuroGEARS Ltd., licensed
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

## Presenting

- <kbd>F</kbd> — full screen
- <kbd>S</kbd> — speaker notes window
- <kbd>O</kbd> — slide overview
- <kbd>←</kbd> / <kbd>→</kbd> — move between topics, <kbd>↑</kbd> / <kbd>↓</kbd> — move within a topic

To print a deck to PDF, append `?print-pdf` to its URL and use the browser's
print dialog.

See [Authoring slides](authoring.md) for how to add a new deck.
