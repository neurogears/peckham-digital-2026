# Showcase

Finished pieces that show a few things Bonsai can do beyond the live demo. Some were built by the Bonsai team for the Bonsai Foundation booth at the Society for Neuroscience meeting in 2025. They are yours to run, hack, break and take apart.

Each demo lives in its own folder. Every demo runs in the workshop environment you set up in [Getting Started](../worksheets/01-getting-started.md), so open them from the same `Bonsai.exe`. A demo that needs extra hardware, like the pan-tilt camera, says so on its page.
