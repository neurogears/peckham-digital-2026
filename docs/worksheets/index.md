# Worksheets

Hands-on material for **Bonsai: Wiring the World into Sound and Image**.

The session has three parts. Worksheet 1 is for before you arrive. Worksheet 2 is the
live demo we build on stage, written out step by step so you can rebuild it, catch up, or
copy any stage straight into your own editor. Worksheet 3 is the hands-on part: fork the
demo and make it yours.

| Worksheet | Topic |
| --- | --- |
| [1: Getting Started](01-getting-started.md) | Installing Bonsai, opening the workshop environment, your first stream. |
| [2: The Live Demo](02-live-demo.md) | Camera in, microphone in, one image out through a shader, controls on top. |
| [3: Fork It](03-fork-it.md) | Remix prompts: swap a sensor, change a transformation, remap input to output. |

## Conventions

- `CameraCapture`: a name in code font is an operator to add to a workflow. Type it into
  the toolbox search box and press Enter, or drag it onto the canvas.
- **Exercise** headings mark something for you to build.
- Every workflow figure has a copy button in its top right corner. Click it, then click on
  the empty canvas in Bonsai and paste. The nodes appear wired up and configured.

> [!TIP]
> Pasting only works if your Bonsai has the same packages installed as ours. Worksheet 1
> shows how to open the workshop environment, which has everything preinstalled.
